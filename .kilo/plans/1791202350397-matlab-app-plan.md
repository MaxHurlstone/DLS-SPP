# MATLAB App: SPP Slope Error Calculator (3-Tab App)

## Objective

Convert the `mvp/` scripts into a 3-tab MATLAB App Designer app (`SloperApp.mlapp`) that preserves all analysis + export logic while adding multi-dataset management, live-updating plots, and GUI file/folder selectors.

## Existing Files (unchanged)

| File | Purpose |
|------|---------|
| `mvp/sloper.m` | Analysis engine — reads .txt, interpolates, computes gradients |
| `mvp/sloper_export.m` | Export engine — writes tab-delimited tables |
| `mvp/crystal_footprint.m` | **Reference only** — shows current parameter values and plot layout |

No changes to `sloper.m` or `sloper_export.m`.

## App Structure

- **Framework:** MATLAB App Designer (`.mlapp` file). The app uses a `uigridlayout`-based single-page layout with `uitabgroup` + `uitab` for the 3 tabs.
- **File:** `SloperApp.mlapp` created directly via App Designer (or, if code-only, assembled as a valid `.mlapp` ZIP with `layouts/` XML + `code/` callbacks).
- **Backing `.m` class file:** Generated automatically by App Designer from the `.mlapp`.

## State Management (App Properties)

```matlab
properties (Access = private)
    % List of imported datasets
    % Each entry: struct with fields:
    %   name       (string)   — user-given label
    %   filepath   (string)   — full path to .txt source
    %   sloperOutputs — {X,Y,U,V,W,S_lon,S_sag,x,y,u,v,w}
    Datasets          cell  = {}

    % Currently selected dataset index (Tab 2 & 3)
    SelectedIndex   double = 0

    % Export target directory
    ExportDir       string = ""
end
```

## Tab 1: Import Data

### UI Components

| Component | Type | Description |
|-----------|------|-------------|
| `FileButton` | `Button` | Opens `uigetfile('*.txt')` |
| `FilePathField` | `EditField` (read-only) | Shows selected file path |
| `DatasetNameField` | `EditField` | User types a name for this dataset |
| `AddDatasetButton` | `Button` | Validates, runs analysis, appends to `Datasets` list |
| `DatasetListBox` | `ListBox` | Shows all added dataset names |
| `RemoveDatasetButton` | `Button` | Removes selected entry from list |
| `StatusLabel` | `Label` | Feedback messages |

### Logic
1. User clicks `FileButton` → `uigetfile` opens → path written to `FilePathField`.
2. User types a name in `DatasetNameField`.
3. User clicks `AddDatasetButton`:
   - Validate: file exists, name non-empty, name unique.
   - Call `sloper(filepath, Nxx_default, Nyy_default, FID_default, order_default, sym_default)` immediately so the outputs are stored.
   - Append `{name, filepath, outputs}` to `Datasets`.
   - Refresh `DatasetListBox` items.
4. `RemoveDatasetButton`: remove selected from `Datasets`, refresh list.
5. On Tab 2 selection, default params (Nxx=100, Nyy=20, FID=false, order=3, sym=false, Np=10) are used until the user changes them — the stored outputs from import time are used as the initial plot.

## Tab 2: Analysis

### UI Components

| Component | Type | Description |
|-----------|------|-------------|
| `DatasetDropdown` | `DropDown` | Populated from `Datasets` names |
| `NxxField` | `Spinner` | Grid points X (default 100) |
| `NyyField` | `Spinner` | Grid points Y (default 20) |
| `FIDCheckBox` | `CheckBox` | Polynomial fit toggle |
| `OrderField` | `Spinner` | Polynomial order (default 3), enabled only when FID checked |
| `SymCheckBox` | `CheckBox` | Symmetry toggle |
| `NpField` | `Spinner` | Sub-sample count for line plots (default 10) |
| `RunButton` | `Button` | Re-run analysis with current params |
| `ContourPlotAx` | `Axes` | Figure 1 replica — contourf subplots (S_sag top, S_lon bottom) |
| `LinePlotAx` | `Axes` | Figure 2 replica — 4 line-plot subplots |

### Logic
- **Auto-update:** Changing `DatasetDropdown`, `NxxField`, `NyyField`, `FIDCheckBox`, `OrderField`, `SymCheckBox`, or `NpField` triggers a re-run and re-plot.
- **Re-run steps:**
  1. Get selected dataset's filepath from `Datasets`.
  2. Call `sloper(filepath, Nxx, Nyy, FID, order, sym)`.
  3. Update stored outputs for that dataset in `Datasets`.
  4. Clear `ContourPlotAx` and `LinePlotAx`.
  5. Recreate plots:
     - **Contour plot** (Fig 1): Use `contourf` on S_sag and S_lon with `colormap bone`, add colorbars.
     - **Line plot** (Fig 2): Loop `i=1:Np`, plot 4 subplots: W vs X, W vs Y, S_sag vs X, S_lon vs Y, each with `hold on`.
- `RunButton` can also trigger the same logic (belt-and-suspenders).

### Recommended plot layout
```
Tab 2 layout:
+--------------------------------------------------+
| Parameters panel (left) | Plot area (right)       |
| DatasetDropdown         |  +------------------+  |
| Nxx  Nyy  Np           |  | Contour (S_sag)   |  |
| FID  Order  Sym        |  +------------------+  |
| [Run]                  |  | Contour (S_lon)   |  |
|                         |  +------------------+  |
|                         |  | 4-panel line plot |  |
|                         |  +------------------+  |
+--------------------------------------------------+
```
Use `uigridlayout` with 2 columns — left column for param controls, right column for plots.

## Tab 3: Export

### UI Components

| Component | Type | Description |
|-----------|------|-------------|
| `ExportDatasetDropdown` | `DropDown` | Populated from `Datasets` names |
| `ExportDirField` | `EditField` (read-only) | Shows selected export folder |
| `BrowseExportDirButton` | `Button` | Opens `uigetdirectory()` / `uigetfolder` |
| `DverField` | `EditField` | Text entry for dver |
| `BlnameField` | `EditField` | Text entry for blname |
| `OptnameField` | `EditField` | Text entry for optname |
| `ScenameField` | `EditField` | Text entry for scename |
| `ExportButton` | `Button` | Runs export |
| `ExportStatusLabel` | `Label` | Success/error message |

### Logic
1. `BrowseExportDirButton` → opens folder picker → sets `ExportDir`.
2. `ExportButton`:
   - Validate: dataset selected, ExportDir non-empty, all fields non-empty.
   - Build `expname` from `dver-blname-optname-scename-date`.
   - Get stored outputs from `Datasets[selected]`.
   - Call `sloper_export(ExportDir, expname, x, y, X, Y, u, v, w, U, V, W)`.
   - Show confirmation.

## Implementation Steps (ordered)

### Step 1: Create App Skeleton
- Create `SloperApp.mlapp` using App Designer or construct the `.mlapp` ZIP with proper `layouts/` + `code/` + `metadata.xml`.
- Define the 3-tab layout with all UI components listed above.
- Add private properties: `Datasets`, `SelectedIndex`, `ExportDir`.

### Step 2: Implement Tab 1 (Import)
- Wire `FileButton` to `uigetfile`.
- Wire `AddDatasetButton` to validate input, call `sloper(...)` with defaults, store result in `Datasets`.
- Wire `RemoveDatasetButton` and refresh logic.
- Add output arguments to confirm storage worked.

### Step 3: Implement Tab 2 (Analysis)
- Wire `DatasetDropdown` change callback.
- Wire all parameter controls (`NxxField`, `NyyField`, etc.) to a shared `updateAnalysis` callback.
- Implement `updateAnalysis`:
  1. Read current param values.
  2. Call `sloper(...)` with selected dataset's filepath.
  3. Clear and redraw both axes with plots matching `crystal_footprint.m` style.
- Use `contourf` for sagittal/longitudinal plots, `colormap bone`, matching colorbar labels and font sizes.
- Use the 4-subplot loop for line plots matching Fig 2.

### Step 4: Implement Tab 3 (Export)
- Wire `BrowseExportDirButton` to `uigetdirectory`.
- Wire `ExportButton`:
  1. Read all field values.
  2. Generate date string and build `expname`.
  3. Extract selected dataset's outputs.
  4. Call `sloper_export(...)`.

### Step 5: Wire Cross-Tab State Propagation
- When a dataset is added in Tab 1, Tab 2's `DatasetDropdown` refreshes.
- When Tab 2 re-runs analysis, the updated outputs are stored back into `Datasets` so Tab 3 uses the latest values.
- Tab 3's `ExportDatasetDropdown` reflects the same dataset list.

### Step 6: Verify
- Open `SloperApp.mlapp` in App Designer (or run `SloperApp` from command line).
- Test: Import `test_data/test.txt` → name it → switch to Tab 2 → plots appear.
- Test: Change Nxx → plots update.
- Test: Change FID/order → plots update.
- Test: Add second dataset → switch between them in Tab 2.
- Test: Export with metadata → verify files appear in export dir.

## Risks & Mitigations

| Risk | Mitigation |
|------|------------|
| `.mlapp` ZIP format fragile | Use MATLAB App Designer to create the initial blank app, then edit code-behind. Keep backups of layout XML. |
| Slow re-plot on every keystroke | Only re-run when value *changes* (ValueChangedCallback, not continuous). For spinners, this is the default behavior. |
| Large datasets slow the app | Store computed outputs once per dataset; only recompute when params change. |
| `colormap bone` affects both subplots | Set `colormap` separately per subplot or call `colormap` after both are drawn and rely on it applying to the current `subplot` / `axes` only. Use `axes` handles. |
